# Practice 5 — Python Regular Expressions (RegEx)

## 📌 Overview

This practice focuses on mastering **Regular Expressions (RegEx)** in Python.
The main goal is to learn how to search, match, find, and replace text patterns
using Python's built-in `re` module, and to apply these skills to a real-world
task: **parsing receipt data from `raw.txt`**.

---

## 🎯 Objectives

- Understand RegEx syntax and metacharacters
- Use special sequences (`\d`, `\w`, `\s`, etc.)
- Apply quantifiers (`{n}`, `{n,}`, `{n,m}`)
- Master the core `re` module functions:
  - `re.search()` — find first match
  - `re.findall()` — find all matches
  - `re.split()` — split strings
  - `re.sub()` — replace patterns
  - `re.match()` — match at the beginning
- Use flags like `re.IGNORECASE` and `re.MULTILINE`
- Parse a real receipt file and extract structured data
